# MySQL
В данном проекте проведён анализ транзакционных данных с использованием SQL.  Цель - выявить клиентов с непрерывной покупательской активностью и рассчитать ключевые метрики по ним.

Задачи:
Найти клиентов, совершавших покупки каждый месяц в течение года.
Выявить:
средний чек,
средние траты в месяц,
количество транзакций.

Проанализировать метрики по месяцам:
средний чек,
количество транзакций,
количество уникальных клиентов,
среднее число покупок на клиента.
